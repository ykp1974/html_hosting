この講義では、熱力学における「エントロピー」の概念について導入し、その直観的な意味と計算方法、そして熱力学第二法則との関係を解説します。エントロピーは自発的変化の方向性を特徴づける状態量であり、「乱雑さ」と関連付けられます。断熱自由膨張の例を通じて、非平衡過程におけるエントロピー変化の計算に可逆経路を用いる重要性が示され、最終的に系と外界を含む全エントロピーが常に増大または一定となることが熱力学第二法則として確立されます。
主要な論点

自発的変化の方向性

  • 世の中の現象には、自発的に一方向にしか進まない変化がある。
例1: 25℃の部屋で60℃のコーヒーを放置すると、25℃まで冷める。自発的に熱くなることはない。
例2: 箱の片側に集められた粒子は、放置すると箱全体に広がる。自発的に一箇所に集まることはない。

エントロピーの導入と定義

  • 上記のような自発的変化の方向性を特徴づける物理量として「エントロピー (Entropy)」が導入される。
  • 記号は「S」。
  • エントロピーは「状態量」である（系の状態だけで決まる量）。
  • 微小なエントロピー変化 (dS) は、準静的過程において以下のように定義される。
dS = d'Q / T
  • ここで、d'Q は準静的に系に与えられる熱量、T は系の絶対温度である。この定義は可逆過程（準静的過程）にのみ適用される点に注意が必要。

エントロピーの直観的な意味

  • 統計力学の有名な式「S = kB log W」を用いると、エントロピーは系の「乱雑さ（ミクロ状態の数）」と関連付けられる。
  • 系はより乱雑な状態へと自発的に変化する傾向がある。
  • 熱（d'Q）は粒子の乱雑な運動を引き起こすが、仕事は規則的な運動を引き起こすため、エントロピー変化には熱が関係する。
  • 温度（T）で割る理由は、元の乱雑さに対して、どれだけ乱雑さが増加したかを示すためである。高い温度（既に乱雑）で熱を加えても、低い温度（規則的）で熱を加える場合に比べて相対的な乱雑さの増加は小さい。
dS = d'Q / T = (乱雑さの増加) / (元の乱雑さ)

熱力学第二法則（エントロピー増大則）

  • 一般の過程では、クラウジウスの不等式として以下が成り立つ。
dS ≥ d'Q / T
  • 等号は準静的過程（可逆過程）で成立し、不等号は非準静的過程（不可逆過程）で成立する。
  • 特に、断熱過程（d'Q = 0）においては、エントロピー変化は以下のようになる。
ΔS ≥ 0 （断熱過程）
  • つまり、断熱過程ではエントロピーは減少しない。等号は断熱準静的過程で成立する。

狭い意味でのエントロピー増大則

  • 孤立系における自発的変化では、エントロピーは必ず増大する。
ΔS > 0 （孤立系, 自発）
POINT: 一般の系ではエントロピーは減少することもあり得るが、孤立系ではエントロピーは減少しない。

例：理想気体の断熱自由膨張

  • 設定: 断熱容器内で理想気体がP1, V1, T1の状態から、真空部へ膨張しP1/2, 2V1, T1の状態へ変化する。これは非平衡（不可逆）過程である。
  • 課題: 非平衡過程であるため、dS = d'Q/T を直接適用してΔSを計算することはできない。
  • 解決策: エントロピーは状態量であるため、始状態と終状態を結ぶ任意の可逆経路（準静的過程）を選び、その経路に沿ってΔSを計算すればよい。
  • 選択経路: 等温準静的膨張。理想気体の断熱自由膨張では温度変化がない（ΔT=0）ため、等温過程と一致する。
計算過程:
1. 仕事 (W) の計算: W = -∫PdV = -nRT1 ln(V2/V1) = -nRT1 ln 2。
2. 熱量 (Q) の計算: ΔU = Q + W (熱力学第一法則)。理想気体の等温過程ではΔU=0。よって Q = -W = nRT1 ln 2。
3. エントロピー変化 (ΔS) の計算: ΔS = ∫(d'Q/T) = Q/T1 = (nRT1 ln 2) / T1 = nR ln 2。
  • 結果: ΔS = nR ln 2。nR ln 2 > 0 であるため、断熱自由膨張においてエントロピーは増大することが確認された。

全エントロピー変化

  • 系のエントロピー変化 (ΔS_系) とは別に、外界のエントロピー変化 (ΔS_外) も考慮する必要がある。
  • ΔS_外 = ∫(-d'Q / T_外)。ここでT_外は常に熱平衡状態とみなせる外界の温度である。
  • ケース1: 断熱自由膨張（非平衡過程）
    • ΔS_系 = nR ln 2
    • ΔS_外 = 0 （断熱過程のため熱の出入りなし）
    • ΔS_全 = ΔS_系 + ΔS_外 = nR ln 2 > 0
  • ケース2: 等温準静的膨張（可逆過程）
    • ΔS_系 = nR ln 2
    • ΔS_外 = -Q/T1 = -nR ln 2 （系が受け取った熱Qが外界から失われる）
    • ΔS_全 = ΔS_系 + ΔS_外 = 0
POINT: 系のエントロピー変化 (ΔS_系) は負になる場合もあるが、系と外界を含めた全エントロピー変化 (ΔS_全) は必ず0以上である（熱力学第二法則）。全エントロピー変化が負になるような過程は起こり得ない。

実用的な計算：定圧準静過程

  • 実在物質のエントロピー変化を計算する際には、定圧熱容量 (Cp) を用いると便利である。
  • 定圧熱容量 Cp = d'Q / dT であるため、d'Q = Cp dT と書ける。
  • これをエントロピー変化の式に代入すると、dS = Cp dT / T となる。
  • Cpが一定とみなせる温度範囲においては、ΔS は以下のように計算できる。
ΔS = ∫(Cp/T)dT = Cp [ln T] from T1 to T2 = Cp ln(T2/T1)
  • Cpが温度依存性を持つ場合は、Cp/T を温度Tでプロットし、T1からT2までの面積を計算することでエントロピー変化を求められる。
結論・今後の注目点
結論

エントロピーは自発的変化の方向性を示し、「乱雑さ」の尺度として機能します。熱力学第二法則が示すように、孤立系における自発的変化では全エントロピーは増大します。系のエントロピーが減少する過程も起こり得ますが、その際には外界のエントロピー増大が伴い、全エントロピーは必ず0以上を保ちます。実在物質のエントロピー変化は定圧熱容量などの情報から計算可能であり、これは化学反応の進行方向や物理現象の可否を予測する上で極めて重要な概念です。
