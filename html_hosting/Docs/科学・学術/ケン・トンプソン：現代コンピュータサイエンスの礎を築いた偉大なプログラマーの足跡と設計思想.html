ケン・トンプソン：現代コンピュータサイエンスの礎を築いた偉大なプログラマーの足跡と設計思想

動画参照：【歴史】Unix、grep、UTF-8、Go言語を作った男。ケン・トンプソン物語。

1. エグゼクティブ・サマリー

現代のITインフラ（UNIX、Linux、macOS、C言語、Go言語、grep、UTF-8）の原流を辿ると、一人の天才プログラマーに到達します。それがケン・トンプソン（Ken Thompson）です。「自分が使いやすい最高の道具を自分で作る」「無駄な複雑さを排除し、徹底的にシンプルを保つ」という現代コンピュータサイエンスの設計思想を形作った彼の足跡を振り返ります。

2. 生い立ちと合理主義の萌芽

  • モノづくりの原点：転勤族の少年時代、行く先々で玩具を置き去りにされたため自らゼロからモノを制作。
  • 二進数の追求：学校の宿題をすべて二進数で解いて提出。「面倒を減らすためにシステム自体を変える」原点に。
  • UCバークレー：深夜のコンピュータセンターを占有し、プログラミングの中毒的魅力に没頭。

3. ベル研究所と「Unix」の誕生

  • Multicsの挫折：巨大で複雑化したMultics計画の失敗を受け、ベル研究所は撤退。
  • PDP-7での反逆：宇宙旅行ゲームを動かすため、小型ミニコンで数週間のうちにOSの原初形（Unix）を単独開発。
  • Unix哲学：「1つのことだけをうまくやる」「小さな道具を組み合わせる」「パイプ処理」。

4. 数々の革命的発明と歴史的業績

正規表現と「grep」

エディタ改良の過程で有限オートマトン理論をテキスト検索に応用し、正規表現および「grep」コマンドを生み出す。

C言語と移植性

B言語の限界を超え、デニス・リッチーと共にC言語を開発。OSをC言語で書き直し、高い移植性により世界標準へ。

UTF-8の発案

多国籍文字コードの混乱を解決するため、食堂の紙ナプキンの上で「UTF-8」の仕組みを書き上げ一晩で実装。

Go言語の開発

Google参画後、複雑化するC++に反発。ロブ・パイクらと「1時間で覚えられる言語」としてGo言語（Golang）を設計。

5. 結論：ケン・トンプソンの設計哲学

ケン・トンプソンが半世紀以上にわたってITインフラに残した影響の根底にあるのは、**「徹底的なシンプルさの追求」**と**「現場の課題を自らの手で直ちに解決する実用主義」**です。彼が生み出した道具と哲学は、今なお世界中のソフトウェア開発の基盤として息づいています。
