Anthropic（ANT）上場初日の株価を読む

〜 財務・ロックアップ・OpenAIの上場への影響 〜

記事へのリンク
エグゼクティブ・サマリー：
Anthropic（ANT）は2026年11月19日（日本時間20日）にNasdaqへ上場し、初日の終値は97.17ドルでした。これは公開価格83ドルを17％上回りましたが、初値の111.50ドルからは13％下落した結果です。上場初日の株価は、売り出し株の需給が強く影響しており、長期的な事業への期待を直接示すものではありません。財務面では、2026年7〜9月期の売上は170億ドルと前年同期比約12倍に急成長していますが、営業損益は赤字に転じています。議決権は創業者側に集中し、株主が経営に与える影響は限定的です。ロックアップ解除は段階的に行われ、特に決算発表後に大量の株が売却可能となるため、今後の株価に影響を与える可能性があります。OpenAIの上場時期や値付けにも、Anthropicの株価動向が影響しうると考えられます。
1. 株価が語ること、語らないこと
項目 事実 編集部の見立て・結論
初日の値動き 公開価格83ドル、初値111.50ドル、終値97.17ドル。公開価格を17%上回るも、初値からは13%下落。売り出しは9億8000万株（発行済み株式の約7.4%）。 買いたい人が売りたい人を大きく上回ったことで初値は高騰したが、その後売り戻しが発生。初日の株価は「いま売買された株の需給」を語るものであり、Anthropicの数年先の姿への期待の総量を示すものではない。
SpaceXとの比較 SpaceXは上場初日に公開価格を19%上回ったが、数カ月後には公開価格を下回った。ただし、SpaceXとAnthropicは事業内容や市場で売買できる株の比率が異なる（SpaceXは約4〜5%、ANTは約7%）。 一つの前例からAnthropicの行方は読めない。
2. 財務が示す期待の大きさ
項目 事実 編集部の見立て・補足
2026年7〜9月期売上 170億ドル（前年同期13億8200万ドルから約12倍増）。 —
営業損益 4〜6月期の9億7400万ドルの黒字から、7〜9月期は5億6700万ドルの赤字（営業利益率マイナス3％）に転換。 損失の大半が非現金という説明は、現金が出ないことを意味するが、事業が採算に向かうことを意味しない。
9カ月の純損失 1040億ドル。うち約9割（943億ドル）は転換社債・デリバティブ負債・SAFEの公正価値変動による会計上の損失で、現金の出入りは伴わない。 —
現金・現金同等物 9月30日時点で956億ドル。上場の手取りと私募の資金は含まれない。 —
計算資源・インフラの契約上の義務 約9009億ドル。うち1年以内に支払うのは約707億ドル。 この確約は売上が伸びる前提で結ばれており、伸びなければ別の形で重さが現れる可能性がある。
終値97.17ドルでの評価額 発行済み株式（約132億株）で約1.28兆ドル（年換算売上約19倍）。完全希薄化後（約181億株）で約1.76兆ドル（年換算売上約26倍）。 終値は「売上が今の2〜3倍になり、その倍率が10倍前後に落ち着く」という道筋を市場が一定程度織り込んだ姿と読み取れる。
💡 売上の数え方に関する注意点：
AnthropicはAmazonやGoogleなどのクラウド経由の売上を総額で計上すると報じられている一方、OpenAIは提携先の取り分を差し引いた純額で数えるため、両社の売上や倍率を単純に比較することは難しい。
3. 議決権とロックアップの構造

議決権の集中

Class Fの1株（創業者側が保有）が株主総会の議決権合計の50.1%を占める。公開市場の株主の議決権は全体の約6%に留まる。

Class T（長期利益信託が保有）はClass T取締役を選任・解任する権限を持ち、その取締役が取締役会の過半を占める。

ロックアップの概要

取締役・役員およびほぼ全ての株主が、計約155億株についてロックアップ（売却制限）の対象。共同創業者と0.5%超の株主は最長365日。

解除は一日ではなく、23回に分かれ、多くは決算発表に連動する。

段階的な解除日程

取引初日に非創業者の取締役・役員、現旧従業員・コンサルタントの保有分最大10%（3億1500万株）が売却可能。

12月15日ごろ（27日目）、1月5日ごろ（48日目）にそれぞれ3億300万株。

2026年通期決算発表の2取引日後には17億株。

⚠️ 編集部の見立て（仮説）：
議決権集中と公益法人
米国のテック企業では珍しくないが、Anthropicは「公益」と取締役会の過半を選ぶ信託が重なる点が特徴。株主利益と公益が衝突した際、どちらが優先されるかは不透明。
ロックアップ解除の影響
上場後の数週間から数カ月は、「誰が、いくらで売るか」の影響が大きい。需要が強ければ供給は吸収されるが、逆なら価格は重くなる。
4. AI産業への手がかりと社会の受け止め
項目 事実 編集部の見立て・仮説
計算資源の資金調達 Anthropicは計算資源などに約9009億ドルの支出を確約しており、資金調達が公開市場に移った。 —
買い手に出資する売り手 Nvidia、Google、AMD、Broadcom、Micron、Microsoft、TSMC Partnersの7社が公開価格で私募を引き受けた。これらの企業はGPU、チップ、メモリ、クラウドなどを提供する売り手である。 仮説A: 売り手が株主になることで長期の供給確保と深い関係が示される。仮説B: 売り手の出資は、買い手の需要が売り手の資金なしでも成り立つかを見えにくくする可能性がある。
社会の受け止め 機関投資家と引受会社からの申込は売り出し株数の約6倍と報じられた。 日本の個人投資家向けに日本枠（30億〜35億ドル）が用意され、上場後は通常の米国株として購入可能。 Claude利用者や開発者、従業員、AI安全性研究者、日本の読者全般の声はまだ聞こえていない。
5. OpenAIの上場への影響｜三つの仮説
項目 事実 仮説と評価
OpenAIの上場状況 2026年6月8日に非公開で上場申請（S-1）を提出。時期は未定で、Altman氏は2026年の上場を否定し、2027年を検討中と報じられている。 —
売上・損失の比較 2026年7〜9月期の売上はAnthropicが170億ドル、OpenAIが約100億ドル。売上の数え方が異なるため単純比較は困難。OpenAIの同期調整後営業損失は約109億ドルで、大きな赤字が続く。 —
仮説①：ANTの倍率がOpenAIの値付けの物差しになる OpenAIは評価額1.4兆ドル、年換算売上500億ドルで約28倍と報じられており、ANTの終値ベースの約19〜26倍より高い。 売上の数え方が異なるため、単純比較はできない。物差しにはなりうるが、売上定義をそろえる作業が必要。
仮説②：AI関連の資金がANT側に吸い上げられる ANTは公開売り出しと私募で合計1073億ドルを集めた。 指数の下げとANTの因果関係は不明。OpenAIも非公開で資金調達を継続しており、保留。
仮説③：ANTの値動きがOpenAIの上場時期を左右する SpaceXは初日高騰後に公開価格を割った。ANTもロックアップ解除の波を迎えるため、OpenAIはその結果を見てから動く可能性がある。 ANTの値動きは判断材料の一つになりうるが、OpenAIの時期は自社の資金繰りや法人構造など、ANTの株価とは関係しない要因でも動くため、決め手とまでは言えない。
結論・今後の注目点

Anthropicの上場初日の株価97.17ドルは、短期的な需給の結果であり、長期的な事業への期待の総量を読み切るものではありません。 今後の注目点は、以下の「二つの時計」の動きです。

短い時計（需給）： ロックアップの解除による供給の波が株価にどう影響するか。特に2026年通期決算発表後（17億株）と2027年1〜3月期決算発表後（30億株）の大きな節目。
長い時計（事業）： 約9009億ドルの計算資源確約に見合った売上成長が続くか、損益が黒字に戻るか、公益法人としての仕組みが公開会社の圧力の下で機能するか。

これらの動きが、AI産業全体の投資環境やOpenAIの上場時期と値付けに影響を与える可能性があります。
