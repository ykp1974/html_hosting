エグゼクティブ・サマリー

実質賃金下落とインフレが共存する「日本型スタグフレーション」の進行により、かつての「デフレ前提のライフプラン」は崩壊した。本書の結論は「国家への依存を捨て、自助による資産防衛を徹底すること」にある。

1. 日本を蝕む「マイルドな地獄」

賃金の現実

名目賃金の上昇を物価上昇が上回る「実質賃金の低下」が4年連続で進行。働いても豊かになれない構造。

国家依存の限界

少子高齢化で社会保障（年金・医療）の細りは不可避。預貯金・保険という「古い資産防衛策」はもはやリスクである。

2. 生存のための資産防衛戦略（自助の装備リスト）

  • リテラシーの装備：感情論を排し、金利・為替の仕組みを根本から理解する。
  • 運用段階：初級は預金・債券・投資信託。上級は局面に応じた戦術やデリバティブを射程に入れる。
  • 基本方針：一発逆転を狙うのではなく、正しい順序で資産を組み立てる長期視点の「単力」を重視。

3. 世界との格差：6000万人ミリオネア時代

米国では人口の7%がミリオネアという「一般階層化」が進む一方、日本は減少傾向。また、学歴インフレの加速とともに、「昭和的なホワイトカラー優位」の神話は崩壊している。

4. 批判的視点（衰退論への異論）

本書の悲観論に対しては、専門家から以下の指摘もなされている。

  • 日本は失業率が低く生活水準は改善し続けている（カーチス教授）。
  • スタグフレーションという定義そのものへの疑問（伊藤忠総研）。
  • 解決策は「個人防衛」ではなく「企業の生産性向上」にある（RIETI）。

結論

『プアジャパン』は悲観論の書ではなく、「公助」に頼れなくなった現代を生き抜くための実践的指南書である。個人として最大限の守備力を固めることこそが、唯一の自衛策である。
