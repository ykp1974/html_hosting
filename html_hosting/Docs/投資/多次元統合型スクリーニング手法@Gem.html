多次元統合型スクリーニング

東証の構造改革とシステム自動化に基づく、新しい投資パラダイム。 PBR1倍割れ是正と資本効率向上を捉え、持続的な超過リターンを目指す革新的手法。

なぜ今、手法の転換が必要なのか

従来のPER/PBRのみに頼った手法は、業績停滞銘柄を拾う「バリュートラップ」のリスクを抱えています。 東証の要請により、企業には「資本効率の是正」という強力な外圧がかかっており、投資家にはその質を見極める多角的な視点が求められています。

スクリーニング重点指標のシフト

⚠️

旧来の課題：バリュートラップ

単なる低PBR銘柄は、成長性の欠如や資本効率の悪さを反映しているに過ぎない場合があります。

🚀

新時代の鍵：資本効率改善

東証の要請により、高ROE維持・増配・自社株買いといった株主還元が、株価反転の強力なトリガーとなります。

4次元統合型フレームワーク

「ガバナンス」「業績」「需給」「テクニカル」の4つの評価軸を統合。 単一点での評価ではなく、立体的なデータ解析により、確度の高い銘柄選定を実現します。

Dimension 1

資本効率・統治

  • • ROE ≥ 10%
  • • PBR ≤ 1.5倍
  • • F-Score ≥ 7点
  • • DOE（株主資本配当率）
Dimension 2

業績モメンタム

  • • EPS 5年CAGR > 0
  • • 営業CF > 当期純利益
  • • 収益の継続性
  • • 利益の「質」の検証
Dimension 3

市場需給構造

  • • 信用倍率の低下傾向
  • • 信用買残の減少
  • • 評価損益率 -15%〜-20%
  • • 需給の「しこり」排除
Dimension 4

テクニカル

  • • 200日移動平均線上抜け
  • • Bollinger -3σ + 下髭
  • • カップウィズハンドル
  • • 最適なエントリー特定

統合評価の視覚化

自動化システムの技術基盤

セキュリティと利便性を両立。ポート開放なしの静的ホスティング連携により、 場所を選ばず最新の銘柄解析結果を安全に閲覧可能です。

1

Data Backend

Linux Server上でPythonが定時実行。J-Quants / yfinanceから構造化データを取得し、 複雑な計算処理（CAGR、移動平均等）を行いJSON出力。

2

Sync & Build

GitHubプライベートリポジトリへの自動コミット。Cloudflare Pagesが変更を検知し、 ダッシュボードを自動ビルド・更新。

3

Safe Access

Cloudflare Accessによる認証。モバイルWebブラウザからセキュアにアクセス。 ポート開放不要のプル型同期を実現。
