02 — 主要な論点

金利の重要性

  • ジム・クレイマーは、金利が株式市場にとって「隠れた希望」か「強気相場の終わりを告げる鐘」のどちらかであると指摘。
  • 10月23日の市場は全体的に下落したが、ナスダックはAI・半導体関連株の売りが一服したことで比較的持ちこたえた。
  • 市場全体の下げ要因は、主に原油価格の高騰と金利上昇。
  • 中東情勢の緊迫化（フーシ派によるサウジアラビアの石油施設や防衛施設への攻撃、ホルムズ海峡での商船への攻撃）が原油価格を押し上げている。
  • 原油価格の上昇は、米債利回りの上昇を招き、株式市場の魅力を低下させる。
  • ジム・クレイマーの番組「Mad Money」は録画放送で、効率的市場仮説の解説に留まったため、市場のリアルタイムな動向についてのコメントはなかった。
  • 次週はMicrosoft、Alphabet、Eli Lilly、Amazon、Intelなどの主要企業の決算発表に加え、FOMC会合での金利決定やPCE物価指数発表など、重要な経済イベントが集中している。

CoreWeaveの事例

  • ジム・クレイマーはCoreWeaveに関する議論において、「金利」が最も本質的な問題であると主張。
  • CoreWeaveが発行した一部の債券利回りは15%に達しており、この水準では追加の資金調達コストが高すぎる。
  • 投資家は、CoreWeaveが15%の借り入れコストでNVIDIAのGPUを購入した場合、投資からのリターンが大幅に削られることを懸念している。
  • CDS（クレジット・デフォルト・スワップ）の解説：企業が債務不履行に陥るリスクに対する保険のような金融商品で、リスクが高いほど保険料（CDS価格）は高くなる。
  • CoreWeaveの5年物CDSは急上昇しており、ロイター通信によると、今後5年間の累積デフォルト確率は約60%と試算されており、信用不安が急速に拡大していることを示唆。
  • CoreWeaveのCDS価格が上昇している主な理由は以下の4点：
    1. 巨額の債務：AIデータセンター建設のため、NVIDIAのGPU大量購入に多額の資金を借り入れている。
    2. 巨額の設備投資による資金流出：急速な成長とGPU・データセンターへの大規模投資により、営業活動からのキャッシュを上回る資金が流出しており、外部資金調達が必要。
    3. 金利上昇：無担保社債の市場利回りが15%まで上昇し、資金調達コストが増大。
    4. 将来のGPU価値の不確実性：ジム・クレイマーはGPU価値が維持されると考えるが、多くの投資家は数年後の価値を懸念しており、担保価値の下落は貸し手の慎重さを招く。
  • ジム・クレイマーは、CoreWeaveの事業モデルに関する議論は、結局のところ金利という本質的な問題から目をそらすものだと結論。
  • CoreWeave単体で見れば、NebiusやIrenといった他のネオクラウド企業よりも問題は少ないと考えているが、これらの企業にとっても金利上昇は最大の懸念材料。

投資家からの質問（Q&A）

  • 債券投資について：金利が上昇している状況で個人投資家が債券を購入する最善の方法について。ジム・クレイマーは株式投資を好むが、債券に投資するならマネー・マーケット・ファンド（MMF）や定期預金（CD）が手軽な選択肢だと回答。ただし、金利条件は頻繁に変わるため常に確認が必要。
  • 住宅関連株について：金利上昇により株価が下落している住宅関連株（例：Builders FirstSource）の買い時について。ジム・クレイマーは「少しずつ買うならあり」としつつも、Home Depot (HD)を推奨。Home Depotは金利変動に大きく左右されるが、経営がしっかりしており、金利が下がれば大きく上昇する可能性があり、配当も得られる点を評価。
  • 投機的銘柄について：Hinge Health (HNGE)とCava Group (CAVA)の2つの投機的銘柄で元本を回収し、「ハウスマネー」で運用している状況について。ジム・クレイマーは「おめでとう！」と称賛し、元本回収済みの状態を理想的な投資の形と表現。両社とも良い会社であり、Hinge Healthはサブスクリプション型で安定した収益が期待でき、Cava Groupも長期的には良い結果を出すと予想している。
  • Microsoftについて：1年間で50%以上株価が上昇したMicrosoftの決算を控えた対応について。ジム・クレイマーはMicrosoftの株価はまだ「ほとんど上がっていない」ようなもので、経営が非常に優れており、特にAzureの好調を予想しているため、そのまま保有を続けるべきだと回答。
  • Oracleについて：数年間保有し含み益があるOracleの売却時期について。ジム・クレイマーは「明日の朝にまず半分売却してほしい」と即答。Oracleの株価の上昇は信じられないほどであり、資金調達コストが上昇している現在、リタイアした人が安全に持ち続けられる株ではないと指摘。残りは状況を見て判断すべきだと助言。

03 — 結論・今後の注目点

CRAMER'S CORE MESSAGE

結局、問題は金利上昇である。

我々は金利の動きを「鷹の目」で監視するべきだ。

個別企業の信用力やGPUの将来価値といった議論は脇に置き、 FRBがインフレ抑制に満足しているか、 そして米債利回りが今後どう推移するかに全神経を集中するべきです。 金利が市場全体の動き、ひいてはAIインフラの成長速度を決定する鍵となります。
