1. エグゼクティブ・サマリー

日本の防衛産業は、一時的な「思惑株」の枠組みを完全に脱し、**「国策・技術革新・グローバル展開が融合する持続的な成長テクノロジーセクター」**へと歴史的構造変革を遂げています。防衛関係費の拡大と利益率上限の引き上げ（最大15%へ拡充）により、本質的なファンダメンタルズが強化されています。

2. 防衛株を突き動かす5つの成長ドライバー

  • 防衛関係費の大幅拡大：GDP比2%方針等を契機に、予算は6兆〜8兆円規模へ段階的に急増。
  • 利益率改善（制度改革）：納入品の想定営業利益率が最大15%へ引き上げられ、持続可能なビジネスへ転換。
  • 地政学リスクの常態化：ウクライナ情勢や台湾有事リスク等を受け、防衛基盤の自律化が世界的なコンセンサスに。
  • 防衛テックへのシフト：鉄のハードウェアから、AI、ドローン、サイバーセキュリティ、宇宙通信へ主軸が移行。
  • 海外展開・国際共同開発：装備品輸出緩和や日英伊共同開発（GCAP）など、世界市場（外需）の取り込みが加速。

3. 防衛御三家の動向と株価調整の背景

防衛御三家の事業特性

三菱重工業：全領域を網羅する国内最大の防衛筆頭企業。
IHI：ジェットエンジン・タービンに強み。次世代戦闘機（GCAP）のエンジン開発を担当。
川崎重工業：潜水艦やヘリコプターなど自衛隊の中核ハードウェアを担う。

最高益でも株価が調整した理由

過去最高益更新の一方で、足元では高値から約2割調整。要因は①短期的な過熱感（PERの急拡大）、②AI・半導体セクターへの一時的な資金シフト、③売買高（出来高）の減少による静観ムードであり、ファンダメンタルズの毀損ではない。

4. 隠れ防衛銘柄・ニッチ企業（宇宙・ドローン・部材）

テラドローン

防衛省等への実用化期待が高まるAI自律型ドローンの代表格。

日本工機

防衛予算拡大の直接的な恩恵を受ける産業・防衛用火薬の専門メーカー。

日本製鋼所 (JSW)

ミサイル発射装置や高度な鉄鋼加工技術を誇るインフラ企業。

日本アビオニクス

赤外線センサーや高度な防衛電子機器に特化。

東京計器

慣性ナビゲーション装置やレーダー関連技術に強みを持つ。

スカパーJSAT HD

宇宙作戦団の活動や安全保障通信の根幹を支える衛星通信インフラ。

5. 結論と投資戦略の示唆

今後の防衛投資は、国内予算の分け合い（内需）だけでなく、世界市場で代替不可能なコア技術を供給する**「Made with Japan」**の視点が不可欠です。短期的な思惑に振り回されず、長期的な国策の潮流と先端テクノロジーの融合を見据えたポートフォリオ構築が求められます。
