# プロンプト
このプロジェクトは、YoutubeやWebサイトのサマリを作成しています。
手順は下記です。
１）Youtube「後で見る」からUrlをコピー、またはサイトURLをコピー
２）Gemini Notebookにソース登録 -> 概要説明資料作成（テキスト）後、Markdown出力
３）２）のMarkDownからHTML出力、本プロジェクトにジャンル別に保存、ビルド後Git反映
４）Netlifyにて自動ビルド＆サイト反映
これら工程を、すこしずつ自動化したいです。

構成が把握できました。自動化案をまとめます。

---

## 自動化案（段階別）

現在の工程を4つに分け、**難易度が低い順**に提案します。

---

### フェーズ1：工程3の自動化（最優先・すぐ着手可能）

**Markdown → HTML変換 + Git反映のスクリプト化**

現在おそらく手動でやっている作業をCLIスクリプト1本にまとめる。

```
md2html.ps1 <MarkdownファイルパスOR文字列> <ジャンル名>
```

- Markdownを受け取りHTMLに変換（既存HTMLのスタイルに合わせる）
- `Docs/<ジャンル>/<タイトル>.html` に保存
- `npm run build` 実行
- `git add / commit / push` まで自動実行

**難易度：低 / 効果：大**

---

### フェーズ2：工程2の部分自動化

**Gemini出力Markdownのクリップボード監視 or ファイル監視**

Geminiからコピーしたあと自動的にフェーズ1を実行。

- クリップボードに.mdテキストが来たら検知 → フェーズ1のスクリプトに渡す
- または指定フォルダ（例：`~/Desktop/inbox/`）にMDファイルを置いたら自動変換

**難易度：中**

---

### フェーズ3：工程1〜2の連携（YouTube URL → 概要取得）

**YouTube URL → テキスト要約の自動化**

- YouTube Data API + 字幕取得 → Claude APIで要約 → Markdownを自動生成
- Gemini Notebookを経由しない形で、URLだけで完結させる

**難易度：高（API連携が必要）/ 効果：最大**

---

### フェーズ4：Webサイト対応

**URL → コンテンツ取得 → 要約**

- サイトURLを入力 → スクレイピング → Claude APIで要約 → Markdown生成

**難易度：高（サイトによってはJSレンダリングが必要）**

---
