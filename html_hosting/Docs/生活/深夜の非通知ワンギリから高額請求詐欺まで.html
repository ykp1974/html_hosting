02 — 主な電話詐欺の手口と目的

👻

① 非通知ワンギリ

深夜帯に電話をかけ、出ないことで通話料発生を避けつつ、回線が生きてるかチェック。支払い能力の有無を確認し、情報として売買される。

支払い能力チェック / 情報売買
💰

② 高額国際電話詐欺

海外からの着信（+から始まる番号）に折り返すと、様々な国を経由させられたり、プレミアムレートナンバー（日本でいうダイヤルQ2）に接続され、1分5000円以上の高額な通話料が請求される。

国際番号 / 折り返し厳禁
👮

③ 警察官なりすまし詐欺

VoIPやPBXなどで実在する警察署の電話番号（末尾が0110のことが多い）を偽装し、警察官を名乗って「あなたの口座が犯罪に使われた」などと嘘を言い、お金を振り込ませようとする。

電話番号偽装 / 送金指示は詐欺

05 — 詳細：警察官なりすまし詐欺の手口

電話番号偽装の仕組み

VoIP インターネット電話サービスで発信者番号を自由に設定。
PBX 企業の電話交換機を不正設定し、発信者番号を変更。
アプリ・Webサービス スマホアプリやWebサービスを介して簡単に番号を偽装。

警察なりすましの具体例

実在の警察署番号（例:末尾0110）を偽装し、 巧妙な話術で金銭を騙し取る。

手口「あなたの口座が詐欺に使われた」と不安を煽り、凍結をちらつかせて警察管理の口座へ送金させる。
被害額福島県で3410万円の被害事例も発生している。

06 — 対策と今後の注目点

危険な電話の種類 特徴 対策
非通知ワンギリ 深夜の着信、出てもすぐ切れる。 迷惑行為に留まる可能性が高いが、気持ち悪い場合は無視。
高額国際電話詐欺 +から始まる国際番号からの着信。 絶対に折り返さない。キャリアや消費生活センターに相談。
警察官なりすまし詐欺 実在の警察署番号（例:末尾0110）を偽装。警察官を名乗り、お金の送金を指示。 警察は電話で送金を指示しない。怪しい場合は一度電話を切り、自分で調べて警察署にかけ直す。
最終的なアドバイス

「怪しい」と思ったら、
まず電話を切る。

「不明な電話番号にはかけ直さない」
「お金の送金指示は詐欺」という原則を徹底する。

特に国際電話（+から始まる）や、実在の機関を名乗る不審な電話には細心の注意を払い、 不確かな情報は自分で確認する習慣を持つことが、被害を防ぐ最も確実な方法です。
