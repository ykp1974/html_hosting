立命館大学教授が推奨する高血圧改善法と室内運動プログラム：ブリーフィング・文書

記事参照：ウォーキングより手軽なのに効果的…立命館大教授が｢血圧を下げるにはこれ｣と勧める"タオル1枚の室内運動"

1. エグゼクティブ・サマリー

高血圧の予防・改善において従来の有酸素運動（ウォーキング等）は天候や関節への負担から継続が困難になるケースがあります。立命館大学の家光素行教授は、ウォーキングより手軽で同等以上の降圧効果が期待できる「タオル1枚」「椅子」「寝たまま」で実践可能な室内運動プログラムを提唱しています [1, 2]。筋肉の伸縮や等尺性収縮を通じて血管を刺激し、血管拡張物質「一酸化窒素（NO）」の分泌を促す「血管のばし」のメカニズムが核心となります [1]。

2. 背景と医学的根拠：「血管のばし」の仕組み

  • 外的制約の排除：猛暑や寒暖差、雨天に左右されず完全な室内で安全に実施できる。
  • 一酸化窒素（NO）の分泌：筋肉を適度な力で動かして血流を一時制限し、力を抜いた瞬間に再開させることで血管内皮細胞が刺激され、強力な血管拡張物質であるNOが放出される。
  • 柔軟性の回復：NOの働きにより硬直した血管壁が拡張し、血圧が自然に低下する [1]。

3. 安全に血圧を下げるための3大注意事項

  • 絶対に呼吸を止めない：力むと血圧が跳ね上がるため（バルサルバ効果）、常にゆっくりした自然な呼吸を継続。
  • 全力で握らない・伸ばさない：タオル運動等は「最大握力の約30%（やや強いと感じる程度）」を厳守 [1]。
  • 体調不良時は見合わせる：異常高値や体調が優れない日は無理をせず控える。

4. 立命館大学・家光教授が考案した「3大室内運動プログラム」

運動プログラム 主な対象部位・手法 所要時間・目安頻度 主なメリット・特徴
① タオルグリップ運動 [1] 前腕・手指（等尺性収縮） 1回約10分 / 週3回（1日おき） タオルを30%の力で2分間握り1〜2分休む。NO分泌効果が高くテレビを見ながら実践可能。
② 椅子を使った室内運動 [2] ふくらはぎ・大腿部（下半身） 1回約5分 / 毎日 浅く腰掛け足を伸ばして足首を動かす。下肢の静脈血を押し戻しデスクワーク疲労も回復。
③ 寝たまま仰向けゆる体操 [2] 全身・四肢末梢（リラクゼーション） 1回約3分 / 毎朝晩 手足を軽く上げてブラブラ揺らす。モーニングサージを抑え副交感神経を整える。

5. 結論

家光教授が提唱する室内運動プログラムは、厳しいトレーニングなしで「タオル1枚」や隙間時間を活用して血管の若返りと血圧改善を達成できる合理的な健康管理法です [1, 2]。生活スタイルに合わせて柔軟に組み合わせ、無理なく継続することが健康寿命の延伸につながります [1-3]。
